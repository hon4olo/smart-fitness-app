# Roadmap maintenance

`ROADMAP_PROGRESS.md` is the canonical index. Detailed status belongs in the focused files in this directory.

Update rules:

- edit only the relevant phase file for ordinary status changes;
- update the index only when priorities, phase ownership, or file structure changes;
- record completed PR numbers and merge SHAs in the relevant phase file;
- do not copy full historical implementation logs into the index;
- Git history remains the archive for superseded roadmap wording.
